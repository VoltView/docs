---
title: Authentication
description: Session tokens and API keys
---

| Credential | Header |
|---|---|
| Session token | `Authorization: Bearer <token>` |
| API key (`vv_...`) | `x-api-key: <key>` |

```bash
curl https://api.voltview.co.uk/v1/sites -H "x-api-key: your_api_key"
```

API keys work only on endpoints marked **API key**, within the scopes and sites you pick when creating the key. They never exceed your own access.

| Scope | Access |
|---|---|
| `sites:read` | Sites, stats, EPCs |
| `meters:read` | Meters and readings |
| `meters:write` | Submit readings, delete meters (admins) |
| `meters:lookup` | Meter lookups (needs meter lookup) |
| `consumption:read` | Consumption data |
| `costs:read` | Costs |
| `emissions:read` | Emissions |
| `invoices:read` | Supplier invoices |
| `tariffs:read` | Tariffs |
| `billing:read` | VoltView invoices (needs billing access) |
| `users:read` | Your profile |

| Status | Meaning |
|---|---|
| `401` | Missing or invalid credential |
| `403` | Key lacks the scope, or no access |
