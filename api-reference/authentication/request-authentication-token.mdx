## Authentication

The VoltView API uses a VoltView API key for authentication.

Include your VoltView API key in the `x-api-key` header on every request:

```bash
curl https://api.voltview.co.uk/v1/sites \
  -H "x-api-key: your_api_key_here"
```

## Error Responses

| Status | Description |
|--------|-------------|
| `401 Unauthorized` | Missing or invalid API key |
| `403 Forbidden` | Authenticated but insufficient permissions |


New scoped keys are managed under [Settings → API keys](/api-keys). They allow
only the listed read routes and selected sites. Existing legacy integrations keep
their original restrictions until replaced or revoked. API-key management itself
requires a signed-in Bearer JWT. The [MCP pilot](/mcp) needs a separate connect
permission and an allowlisted account.
