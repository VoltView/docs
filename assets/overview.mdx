On-site assets are the generation and storage on a site: rooftop solar, ground-mount arrays, and batteries.

VoltView connects to your inverter or installer monitoring portal and reads that data next to the site's meters. Access is read-only. We do not change inverter settings or dispatch batteries.

## What you can see

Together with half-hourly meter data, on-site assets show how much the array generated, how much was used on site, and how much was exported.

If a third party owns the array, they grant VoltView access to the monitoring portal.

## How it connects

Each asset belongs to an existing site and is mapped to that site's import MPAN (and export MPAN if you have one).

You connect with an API token from the monitoring portal, a read-only portal user, or an installer share. A file export is available if the portal has no live feed.

## Coverage

We add OEM portals as customers need them. The current list is on the [solar](/assets/solar) page. If your portal is not listed yet, we can still take a file export.
