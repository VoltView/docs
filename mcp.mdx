description: Connect Codex and Claude Desktop to authorised VoltView data

The internal pilot is read-only. It runs at `https://api.voltview.co.uk/mcp` when
enabled. Your VoltView account must be on the pilot allowlist, and your scoped
API key must include `mcp:connect` plus the data permissions you want to use.
Create the key in [Settings → API keys](/api-keys). Public OAuth connections,
Claude browser connections and write tools are not part of this release.

## Tools

| Tool | Permission | Inputs and output |
| --- | --- | --- |
| `list_sites` | `sites:read` | Optional search. Site IDs, names, postcodes, meter count and recent electricity/gas data quality. |
| `get_site_meters` | `meters:read` | `siteId`. Meter IDs, utility, serial, supplier and active-LOA indicator. |
| `get_consumption` | `consumption:read` | `siteId`, `from`, `to`. kWh by period, read/estimated/revised splits, labels and export kWh. |
| `get_modelled_costs` | `costs:read` | `siteId`, `from`, `to`. Calculated GBP including VAT, estimated-reading shares and export credits. These are not supplier invoice totals. |
| `list_invoices` | `invoices:read` | Optional `siteId`. Document IDs, supplier, invoice number, dates and invoice GBP amount when stored. |
| `get_tariffs` | `tariffs:read` | `siteId`, `utility` (`ELECTRICITY` or `GAS`). Stored tariff/meter IDs, rates, contract dates and rate provenance. |

Only permitted tools appear in discovery. Calling a hidden tool is also denied.
These reads do not refresh data, scrape suppliers, trigger ingestion or buy lookups.

Lists accept `limit` (default 50, maximum 100) and `offset` (default 0). Continue
using `nextOffset` until it is null. Ordering is stable for the same underlying
records, but concurrent updates can change pages. Invoice summaries omit an
entire mixed-site bill if any linked supply is inaccessible or unresolved. They
never return raw PDFs, download URLs, storage paths or unrestricted payloads.

Consumption and cost periods must use ISO timestamps with a timezone. Granularity
defaults to `day`. Consumption supports `hour`, `day`, `week`, `month`, `year`;
costs support `hour`, `day`, `month`. Requests are limited to three years and
1,000 returned buckets; narrow the period or choose a coarser granularity when
asked. Consumption uses `[from,to)`. To match existing REST calculations, hourly
costs include the upper timestamp; daily/monthly costs use UTC days touched by
the period. Choose midnight UTC boundaries for full-day reports. Empty periods
return an empty data array. Missing consumption is null, not a measured zero.

Rate values are decimal strings: `unitRatePence`, `dayRatePence`, `nightRatePence`
are pence/kWh and `standingChargePence` is pence/day. `rateSource`, `rateSourceRef`
and `rateIsEstimated` distinguish evidenced from inferred rates. Reading estimate
labels describe consumption quality and do not establish the quality of the rate.

## Codex

Put only the environment-variable name in your Codex configuration:

```toml
[mcp_servers.voltview]
url = "https://api.voltview.co.uk/mcp"
env_http_headers = { "x-api-key" = "VOLTVIEW_API_KEY" }
```

Provide `VOLTVIEW_API_KEY` through your secret manager or a non-persisted shell
prompt before launching Codex. Do not paste the key into this file. On macOS zsh,
for a terminal-launched Codex session:

```sh
read -rs 'VOLTVIEW_API_KEY?VoltView key: '
export VOLTVIEW_API_KEY
codex
unset VOLTVIEW_API_KEY
```

A desktop launch must receive that environment variable through the app's supported
launch environment; terminal exports are not inherited by an already running GUI
app. Follow [Codex MCP configuration](https://learn.chatgpt.com/docs/extend/mcp?surface=cli).
Restart/reconnect after changing the key and verify tool discovery.

## Claude Desktop

Install the VoltView `.mcpb` file supplied with the pilot, then enter the API key
in the extension's settings. The package bundles its dependencies and only
forwards tool discovery/calls to the fixed hosted endpoint. Its `api_key` setting
is marked `sensitive: true`, so Claude stores the credential securely through
the operating system. Never paste the key into `claude_desktop_config.json`.
See [Claude Desktop extensions and credential storage](https://support.claude.com/en/articles/10949351-getting-started-with-local-mcp-servers-on-claude-desktop).

To rotate, copy the new secret into extension settings or your Codex launch
environment, reconnect, run `list_sites`, then revoke the predecessor in VoltView.
The new key preserves the previous permissions, site selection and expiry.

## Limits and failures

The endpoint accepts stateless Streamable HTTP POST requests. Requests are at
most 64 KiB and each key has 60 requests per minute across all service instances.
Data reads have database timeouts and a 25-second HTTP deadline. Origin-bearing
requests require an explicitly allowed Origin; native clients generally omit it.

HTTP 401 means an unknown, revoked or expired key; 403 means the permission or
pilot access is missing; 429 means wait before retrying; 503 means authorization
or rate-limit state could not be checked. Tool errors never authorize a fallback
to another user's data. Removing a pilot user blocks their next MCP request;
revoking the key blocks REST and MCP on the next request.
